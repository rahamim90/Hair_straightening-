# 1. תוכנית עסקית – עסק החלקות שיער

## 1.1 תמצית מנהלים (למלא בשורה אחת לכל סעיף)
- **מה אני מוכרת:** לא "החלקה" – אלא *שיער חלק, בריא ונוח לניהול לחודשים, בלי לחץ של בוקר*.
- **למי:** `[[ הלקוחה החלומית – למשל: נשים 25–45, שיער מתולתל/קרזי, עובדות, אזור ___ ]]`
- **למה אצלי:** `[[ 2–3 בידולים – למשל: אבחון שיער לפני כל טיפול, חומרים שעברו בדיקה מול הרגולציה, ליווי אחרי טיפול ]]`
- **יעד 12 חודשים:** `[[ ___ ₪ הכנסה חודשית / ___ טיפולים בחודש ]]`

## 1.2 ניתוח מתחרות (לבצע השבוע – 45 דקות)
חפשי באינסטגרם/גוגל "החלקה + [העיר שלך]" ומלאי 5 מתחרות:

| מתחרה | מחיר החלקה (בינוני) | חומר שהיא מציינת | כמה רילס בשבוע | מה עושה טוב | איפה חלשה |
|-------|------|------|------|------|------|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

**מה לחפש:** פערים. אם כולן מציגות רק "אחרי" מבריק – את תציגי *תהליך ואבחון*. אם אף אחת לא מדברת על בטיחות – זה הבידול שלך.

## 1.3 מודל הכנסות – 4 מנועים
1. **טיפולי החלקה** – ההכנסה המרכזית.
2. **טיפולי תחזוקה / שיקום** בין החלקות (מסכות, טיפולי לחות – לפי מה שאת מוסמכת אליו).
3. **מכירת מוצרי בית** מותאמים לאחרי החלקה (מרווח 30–50% בדרך כלל, לבדוק מול הספק).
4. **(שלב מתקדם)** הדרכות / סדנאות למעצבות מתחילות.

## 1.6 ניהול סיכונים
| סיכון | מניעה |
|-------|------|
| תגובה / נזק לשיער או לעור הקרקפת | אבחון + בדיקת קווצה, טופס הצהרת בריאות, עבודה לפי הוראות יצרן בלבד (ראי קובץ 09) |
| חומר שנאסר / קיבל אזהרה | מעקב רבעוני אחרי עדכוני משרד הבריאות |
| עונתיות (חורף חלש יותר?) | חבילות מראש, מבצעי חגים, מנוי |
| תלות באינסטגרם | לבנות רשימת וואטסאפ + גוגל ביזנס |
| שחיקה פיזית | מקסימום טיפולים ביום, הפסקות, יום מנוחה קבוע |
| ביטוח | לברר ביטוח אחריות מקצועית מול סוכן ביטוח |

## 1.7 שגרת ניהול
- **יומי (10 דק'):** לענות לפניות, לעדכן תווית בוואטסאפ, סטורי.
- **שבועי (שעה, יום ראשון):** לתכנן תוכן, לבדוק יומן, לשלוח תזכורות שימור.
- **חודשי (שעתיים):** טבלת KPI, הכנסות/הוצאות, החלטה אחת לשיפור.
