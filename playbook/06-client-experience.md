## 6.2 תסריט וואטסאפ – פנייה ראשונה
```
היי [[שם]] 🤍 כיף שפנית!
כדי שאוכל להגיד לך בדיוק מה מתאים לך ומה המחיר, שלחי לי בבקשה:
📸 2 תמונות של השיער (מאחור ומהצד, באור יום, שיער יבש בלי פן)
וענִי בקצרה:
1. עשית החלקה / צבע / בהרה בחצי שנה האחרונה? מה ומתי?
2. יש רגישות בקרקפת או אלרגיות ידועות?
3. מה הכי מפריע לך בשיער היום?
4. יש תאריך שאת רוצה להיות מוכנה אליו?
```

## 6.4 שאלון בריאות לפני טיפול (לשלוח כטופס גוגל)
> ⚠️ נוסח בסיסי – להתאים להוראות היצרן של החומר שלך ולהתייעץ עם עו"ד/סוכן ביטוח לגבי ניסוח הצהרה מחייבת.
- שם, טלפון, תאריך
- טיפולים כימיים בשיער ב-6 החודשים האחרונים (צבע, בהרה, החלקה, סלסול) + תאריכים
- רגישויות/אלרגיות ידועות (כולל לחומרי קוסמטיקה)
- מצבי קרקפת (פצעים, גירוי, פסוריאזיס, דרמטיטיס)
- הריון / הנקה
- בעיות נשימה (אסתמה וכו')
- **מצב רפואי בכליות או נטילת תרופות קבועות** (רלוונטי לחומרים מסוימים – ראי קובץ 09)
- "אני מאשרת שמסרתי מידע נכון ומלא, ושהוסברו לי הטיפול והוראות ההמשך" ✅
- "אני מאשרת / לא מאשרת צילום השיער לפרסום ברשתות (ללא פנים / עם פנים)" ✅

**אם יש ספק רפואי – לא מטפלים עד אישור רופא.** זה מגן עלייך ועל הלקוחה.

## 6.6 הודעות מעקב
**יום 3:**
```
היי [[שם]] 🤍 רציתי לבדוק – איך השיער מרגיש? הספקת לחפוף? אם יש שאלה, אני כאן.
```

```
[[שם]], כל כך שמחתי לעבוד על השיער שלך! 🤍
אם נהנית – זה ממש יעזור לי אם תכתבי כמה מילים בגוגל (לוקח דקה):
[[קישור לביקורת בגוגל]]
ואם בא לך לשלוח תמונה של השיער בבית – אני מתה לראות 📸
```
**חברה מביאה חברה (מצורף ליום 7):**
```
🎁 מתנה בשבילך: כל חברה שתגיע בהמלצתך תקבל [[הטבה]], ואת תקבלי [[הטבה]] בטיפול הבא.
פשוט שתגיד שהיא הגיעה ממך 🤍
```

## 6.7 שימור – הודעת חידוש (בזמן המתאים לפי הניסיון שלך)
```
היי [[שם]] 🤍 עברו כבר [[X]] חודשים מההחלקה!
איך השיער? אם השורשים מתחילים להרגיש – פתחתי כמה תורים ל[[חודש]].
ללקוחות חוזרות שקובעות השבוע: [[הטבה קטנה]] 🎁
```
**יומולדת:**
```
מזל טוב [[שם]]! 🎂 מתנה ממני: [[הטבה]] בטיפול הבא שלך החודש 🤍
```
**לקוחה שלא חזרה (6+ חודשים):**
```
היי [[שם]], הרבה זמן לא התראינו 🤍 רציתי לשאול – איך השיער? ואם משהו בטיפול האחרון לא היה מושלם – ממש חשוב לי לדעת.
```

## 6.8 טיפול בתלונה (נוסחת L.A.S.T)
1. **Listen** – להקשיב עד הסוף בלי להתגונן.
2. **Apologize** – "אני מצטערת שזו החוויה שלך."
3. **Solve** – להזמין לבדיקה *פיזית* בסטודיו, להציע תיקון לפי מה שנראה.
4. **Thank** – "תודה שאמרת לי ישירות."
**אף פעם** לא להתווכח בתגובות ציבוריות. לענות: "שלחתי לך הודעה פרטית 🤍".
